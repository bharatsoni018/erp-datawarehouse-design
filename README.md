# ICFAI Foundation for Higher Education (IFHE), Hyderabad
## Unified Academic Data Management System

> **Initial Working Prototype**: Multi-dataset integration and unified student 360° lookup using a common primary key (`Enrollment_No`).

---

## 🏛️ Project Overview

The central purpose of this application is to allow an administrator to search for a student's **Enrollment Number** and access all available information about that student from **four independent datasets** in **one unified interface**.

- **Institution**: ICFAI Foundation for Higher Education (IFHE), Hyderabad
- **Application**: Unified Academic Data Management System
- **Active Role**: Admin (`admin` / `admin123`)
